### 🔍 What I do

- **Offensive security / pentesting** - breaking into systems professionally, reporting it responsibly.
- **OSS vulnerability research** - fuzzing and auditing open-source C/C++ and Go projects for memory-safety bugs and crashes.
- **Malware analysis & reverse engineering** - static/dynamic analysis, unpacking, behavioral triage; a deep dive I've been in for the last few years.
- **Community building** — I run **2600 Malmö**, the local chapter of the 2600 hacker meetup: monthly talks, demos, and swapping war stories.

### 📡 2600 Malmö
